feature: iCloud placeholder setup — CKShare, history, documents, CI

Summary
- Add placeholder-first iCloud/CloudKit + Core Data support and tooling:
  - CKShare placeholder flow (ShareFlow) and CKShareMapping helper to persist stable record names.
  - Resilient PersistentHistoryProcessor with TokenStore-backed tokens, batch processing, jittered exponential backoff, resumable batches, and pruning.
  - UIDocument improvements (SampleDocument) implementing NSFilePresenter, autosave, and conflict-change hooks.
  - TokenStore file-backed token persistence (avoid UserDefaults).
  - Diagnostics script + lightweight logger.
  - Unit tests and simulator-based integration tests.
  - CI workflow updated to run unit + simulator integration tests.
  - SwiftLint minimal config and docs updates (BEST_PRACTICES, CONTRIBUTING).

Why this is useful
